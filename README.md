# Vending Machine Pickup Line

Entry for the [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) on make.fun.

`main.py` writes one pickup line — spoken by a vending machine to a passing human — to `/output/entry.txt`:

> I've dropped a thousand snacks, but you're the first one I wanted to keep — press B7 and I'll fall for you, no exact change required.

The line is 133 characters, one line, deterministic: every run writes the same bytes.
